# ILIAS Auto-Downloader (DE)

[↓ English](#ilias-auto-downloader-en)

Ein lokales Browser-Userscript, mit dem du veröffentlichte Dateien aus allen oder einzelnen **ILIAS-Kursen** vollautomatisch herunterladen kannst – ohne dich manuell durch unzählige Kurse, Ordner und Unterverzeichnisse klicken zu müssen.

🔗 [**Funktionsübersicht & ausführliche Installationsanleitung**](https://ddoo.me/ilias-auto-downloader)

<br>

## Funktionen & Highlights

- **Vollautomatischer Download:**<br>
  Durchsucht ausgewählte einzelne Kurse oder alle deine ILIAS-Kurse automatisch nach veröffentlichten Dateien und lädt diese direkt herunter.

- **Intelligenter Abgleich (Delta-Download):**<br>
  Das Script merkt sich lokal im Browser-Cache/Speicher, welche Dateien bereits heruntergeladen wurden. Bei erneuten Durchläufen werden **nur neu hinzugefügte oder geänderte Dateien** heruntergeladen *(solange der Browser-Cache bzw. Website-Speicher nicht geleert wird)*.

- **100 % lokal & datenschutzfreundlich:**<br>
  Die gesamte Verarbeitung sowie die Speicherung des Download-Status finden ausschließlich lokal in deinem Browser statt. Es werden keinerlei Daten an externe Server übertragen.

<br>

## Voraussetzungen & Installation

Um das Script ausführen zu können, benötigst du eine Browser-Erweiterung zur Verwaltung von benutzerdefinierten Skripten (Userscript-Manager), wie zum Beispiel **Tampermonkey** (den direkten Link zur Erweiterung sowie eine bebilderte Schritt-für-Schritt-Anleitung findest du auf [ddoo.me/ilias-auto-downloader](https://ddoo.me/ilias-auto-downloader)).

### Kurzanleitung:
1. Installiere einen Userscript-Manager wie **Tampermonkey** in deinem Browser.
2. Erstelle in der Erweiterung ein neues Userscript und füge den Code aus diesem Repository ein (oder installiere das Script über die Anleitung auf der Website).
3. Öffne deine ILIAS-Plattform im Browser und starte den automatischen Download für deine gewünschten Kurse.

<br>

# ILIAS Auto-Downloader (EN)

[↑ Deutsch](#ilias-auto-downloader-de)

A local browser userscript that automatically downloads published files from all or selected **ILIAS** courses—eliminating the need to manually click through individual courses, folders, and subdirectories.

🔗 [**Feature overview & detailed installation guide**](https://ddoo.me/ilias-auto-downloader)

<br>

## Features & Highlights

- **Fully Automated Downloads:**<br>
  Scans individual selected courses or all of your ILIAS courses automatically for published files and downloads them directly.

- **Smart Delta Check:**<br>
  Remembers locally in your browser cache/storage which files have already been downloaded. On subsequent runs, **only newly added or modified files** are downloaded *(as long as your browser cache/site storage is not cleared)*.

- **100% Local & Privacy-Friendly:**<br>
  All processing and download-history tracking happen strictly locally in your browser. No data is sent to external servers.

<br>

## Requirements & Installation

To run this script, you need a browser extension that supports custom user scripts (a userscript manager), such as **Tampermonkey** (you can find a direct link to the extension and a step-by-step setup guide on [ddoo.me/ilias-auto-downloader](https://ddoo.me/ilias-auto-downloader)).

### Quick Start:
1. Install a userscript manager such as **Tampermonkey** in your browser.
2. Create a new userscript in the extension and paste the code from this repository (or follow the installation guide on the website).
3. Open your ILIAS platform in the browser and start the automated download for your desired courses.

<br>
