# ILIAS Auto-Downloader

Ein lokales Browser-Userscript, mit dem du veröffentlichte Dateien aus allen oder einzelnen **ILIAS-Kursen** vollautomatisch herunterladen kannst – ohne dich manuell durch unzählige Kurse, Ordner und Unterverzeichnisse klicken zu müssen.

🔗 [**Funktionsübersicht & ausführliche Installationsanleitung**](https://ddoo.me/ilias-auto-downloader)


## Funktionen & Highlights

- **Vollautomatischer Download:**
  Durchsucht ausgewählte einzelne Kurse oder alle deine ILIAS-Kurse automatisch nach veröffentlichten Dateien und lädt diese direkt herunter.

- **Intelligenter Abgleich (Delta-Download):**
  Das Script merkt sich lokal im Browser-Cache/Speicher, welche Dateien bereits heruntergeladen wurden. Bei erneuten Durchläufen werden **nur neu hinzugefügte oder geänderte Dateien** heruntergeladen *(solange der Browser-Cache bzw. Website-Speicher nicht geleert wird)*.

- **100 % lokal & datenschutzfreundlich:**
  Die gesamte Verarbeitung sowie die Speicherung des Download-Status finden ausschließlich lokal in deinem Browser statt. Es werden keinerlei Daten an externe Server übertragen.


## Voraussetzungen & Installation

Um das Script ausführen zu können, benötigst du eine Browser-Erweiterung zur Verwaltung von benutzerdefinierten Skripten (Userscript-Manager), wie zum Beispiel **Tampermonkey** (den direkten Link zur Erweiterung sowie eine bebilderte Schritt-für-Schritt-Anleitung findest du auf [ddoo.me/ilias-auto-downloader](https://ddoo.me/ilias-auto-downloader)).

### Kurzanleitung:
1. Installiere einen Userscript-Manager wie **Tampermonkey** in deinem Browser.
2. Erstelle in der Erweiterung ein neues Userscript und füge den Code aus diesem Repository ein (oder installiere das Script über die Anleitung auf der Website).
3. Öffne deine ILIAS-Plattform im Browser und starte den automatischen Download für deine gewünschten Kurse.
